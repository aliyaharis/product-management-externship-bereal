
# Product Management Externship — BeReal

An 8-week Product Management Externship project with Extern focused on identifying and prototyping a product opportunity that could increase BeReal's monthly active users (MAUs) while preserving its core values of authenticity, spontaneity, and low-pressure social connection.

**Role:** Product Management Extern  
**Organization:** Extern  
**Product:** BeReal  
**Duration:** 8 weeks  
**Focus:** MAU Growth · Product Discovery · Feature Development · Prototyping

---

## Externship Project Goal

**The main goal of the project was to identify and design a product opportunity that could increase BeReal's monthly active users (MAUs), while preserving its core values of authenticity, spontaneity, and low-pressure social connection.**

The project involved:

**Product Teardown → User Research → Competitor Analysis → Feature Ideation → RICE Prioritization → PRD → User Flows → Prototype → User Testing**

---

## Discovery

I analyzed BeReal's existing user journey and synthesized user feedback to identify product strengths, friction points, and growth opportunities.

### Key findings

- **Spontaneity and authenticity** are core strengths of the experience.
- Notification reliability and posting time pressure can create friction.
- The recurring daily posting routine can become repetitive.
- Users have limited friend-driven reasons to create additional BeReals outside the daily routine.

## Selected Concept — Friend Prompt

### Problem

**Users have limited friend-driven reasons to create and share additional BeReals outside the recurring daily posting routine.**

### Solution

Friend Prompt allows users to send a personalized prompt to a small group of friends, inviting them to respond with a BeReal. Responses can then be temporarily grouped around the same prompt.

### MAU Hypothesis

Friend Prompt can create personal, friend-driven reasons to open and post on BeReal, adding variety beyond the recurring daily routine.

### Guardrails

- Optional and low-pressure
- No countdown or competition
- No gamification
- No messaging/chat
- Does not replace the daily BeReal
- Keeps the interaction lightweight and authentic

## Key Learnings

- Product discovery requires considering the complete experience, including edge cases and failure states.
- Increasing engagement is not enough; features must preserve the product's core values.
- Strong product decisions balance **user value, feasibility, growth potential, and business impact**.
